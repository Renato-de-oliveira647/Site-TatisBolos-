# Tatis Bolos

Site de confeitaria com cadastro de pedidos, impressão de pedidos e controle de entradas e saídas financeiras.

## Como executar


1. Abra a pasta do projeto no terminal.
2. Rode:

   python -m http.server 8000

3. Acesse no navegador:

   http://localhost:8000

## Funcionalidades

- Cadastro de pedidos
- Listagem de pedidos com status
- Impressão de pedidos
- Registro de entradas e saídas financeiras
- Resumo geral de receitas e caixa
- Armazenamento local no navegador com `localStorage`
